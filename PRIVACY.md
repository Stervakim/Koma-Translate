# Данные и приватность

## Куда что уходит

- Распознавание текста, маска букв, восстановление фона и вёрстка выполняются **внутри браузера**. Отдельного сервера Koma для обработки картинок нет.
- Изображение загружается с сайта или его CDN; модели OCR и дорисовки — из указанных в пакете внешних источников и сохраняются браузером. Эти серверы видят обычные сетевые запросы загрузки.
- Выбранному Google / Яндекс / Groq / API передаются **распознанный текст** и необходимые параметры перевода. При включённом контексте отправляется дополнительный извлечённый текст. Применяются правила выбранного провайдера.
- В режиме Codex текст передаётся уже настроенному локальному мосту и далее сервису Codex. Этот режим не является автономным офлайн-переводом.
- Настройки, пользовательские API-ключи, история и диагностический журнал хранятся в профиле браузера. Ключ отправляется соответствующему API для авторизации; они не встроены в опубликованный пакет. Хранилище расширения не следует считать отдельным зашифрованным сейфом.
- Журнал Koma не отправляется разработчику автоматически. Фильтры исключают изображения, текст перевода и поля ключей; перед отправкой выгруженного журнала всё равно просмотрите его сами.

## Разрешения

| Разрешение | Для чего |
| :--- | :--- |
| Доступ к сайтам | Находить картинки и показывать замену в читалке |
| Хранилище, включая большое | Модели, настройки и история |
| Загрузки | Экспорт результата и журнала по команде пользователя |
| Offscreen / scripting / activeTab / контекстное меню | Обработка и интерфейс расширения |
| Native messaging | Только необязательный режим Codex на настроенном ПК |

Отключайте расширение на сайтах, где оно не требуется. Не публикуйте ключи в issue, скриншотах или журналах.

## Что опубликовано

Готовые CRX, собранный браузерный ZIP, инструкции, авторские иллюстрации интерфейса, SHA-256 и сведения о сторонних лицензиях. В релизы не включены профили браузера, аккаунты, личные настройки, история, дампы, приватный ключ подписи, мост Codex и исходники разработки.

Публичный ключ подписи или идентификатор расширения не является секретом. Как у любого расширения, установочный пакет содержит исполняемый JavaScript; его можно распаковать и исследовать.
