С 0.3.21 фиксированное ограничение 6/4 заменено общим адаптивным бюджетом. WebGPU используется только при поддержке браузера и модели; универсальное ускорение всей главы не гарантируется.

## Что уже проверялось

- Для 0.3.22 локально проходили 203 автоматические проверки; это не гарантия работы всех сайтов.
- 0.3.22 установлена на Edge Canary Android. Полная проверка перевода главы остаётся незавершённой: наблюдался обрыв ответа фонового процесса.
- Отдельный тест дорисовки на одном синтетическом тайле 512 px: ПК — WebGPU/CPU 1,674 с против CPU 14,638 с; Android — 4,579 с против 19,006 с. Это только вычисление, без загрузки и запуска моделей; не время перевода главы. За маской изменённых пикселей не было. Сведения о личном устройстве автора не публикуются.
